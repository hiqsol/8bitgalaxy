1. **Singularity** is the [[Science]] path of [[Goal]]
2. A [[Faction]] reaches **Singularity** at **Check** phase of own
   [[Turn]], when for every [[Class]] it has
   an [[ActiveFor|active]] card that provides that Class at the
   highest [[Level]] of that Class in its faction deck
3. One card per Class, see [[Level]]
4. The faction that reaches **Singularity** wins at once

#### Notes

1. The highest Level is taken from the faction deck, so the path fits
   any deck. In the Human [[Deck]] it takes four active Level 4 cards,
   one per Class
2. The race against [[Twilight]]: [[Research]] leads both to
   **Singularity** and to an empty [[Laboratory]], which triggers
   Twilight
3. Unused cards in [[Hand]] count, they are active: the check comes
   before they go to [[Discard]], see [[Turn]]
