1. **Action** is a part of [[Turn]]
2. **Action** is started by playing a card from [[Hand]], see [[PerformAction]]
3. **Actions** come in two flavours:
	1. [[BasicAction]]s are available at any time.
		1. [[Move]]
		2. [[Transport]]
		3. [[Manage]]
		4. [[Research]]
		5. [[Attack]]
	2. To start a [[TechnologyAction]] one of action participants must provide it as its [[Ability]], see the catalog in [[Technology]]
