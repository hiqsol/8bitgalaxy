1. **Twilight** is the end of the game when no [[Faction]] has won
   before, see [[Goal]]
2. **Twilight** is triggered when all piles of a player's
   [[Laboratory]] are empty
3. The [[Turn]] of the trigger is the last one of the triggering
   player
4. After it every other player makes one last [[Turn]], starting with
   the next player
5. Then the [[Culture]] path decides the winner

#### Notes

1. Named after the Twilight of Twilight Imperium
2. A supply running out ends the game, like Imperium and Tyrants of
   the Underdark, or the Age III deck of Through the Ages
3. The game has no rounds: the game ends when the turn would pass back
   to the triggering player
4. [[Research]] brings **Twilight** closer: a leader on the way to
   [[Singularity]] can close the game before rivals catch up in
   Culture
5. The triggering player picks the timing, the rivals get the last
   word: every rival has exactly one Turn to answer, and Culture
   counts the current state, so the last move is strong
6. **Twilight** is far by intention, a long game like Twilight
   Imperium: [[Singularity]] usually comes first
