1. **Range** is implicit card property
2. **Range** is the [[Distance]] card can cover
3. Mobility types:
	1. Moving - can move on itself, **Range** > 0: [[Ship]], [[Hero]]
	2. Transportable - can't move on itself but can be transported, **Range** = 0: [[Base]], [[Colony]]
	3. Immovable - can not be moved
4. Default value:
	1. Current [[Level]] for moving cards
	2. 0 for [[Structure]]
