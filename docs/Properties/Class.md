1. **Class** is explicit card [[Property]]
2. Each **class** corresponds to the [[Power]] and color:
	- 🔴 [[Military]]		- [[AttackPower]]
	- 🟢 [[Culture]]		- [[CulturePower]]
	- 🟡 [[Production]]	- [[ProductionPower]]
	- 🔵 [[Science]]		- [[SciencePower]]
3. **Class** is independent of [[Origin]] ([[Social]] / [[Industrial]])
4. [[Actor]] card can have a different **class** at each [[End]], the visible one is used
