1. **Size** aka **Weight** is implicit card [[Property]] derived from
   [[Level]], [[ExtraPrice]] and [[Type]]
2. Important for cargo of a [[Move]] - it's required to have enough
   capacity
3. Default value:
	1. Current [[Level]] for [[Hero]]
	2. Current [[Level]] + [[ExtraPrice]]
4. A [[Materials]] or [[Energy]] token's **Size** is its amount: 1 or
   5, see [[Component]]
