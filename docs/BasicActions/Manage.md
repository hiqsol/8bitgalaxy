1. **Manage** is [[BasicAction]] of any [[Class]]
2. **Manage** changes cards:
	1. **Rotate** ([[End]]):
		1. [[Structure]] to strong end - [[Restore]]
		2. [[Structure]] to weak end - [[Deplete]]
		3. [[Actor]] to the other end - switch its [[Class]]
	2. **Shift**:
		1. Between [[Slot]]s within the same [[IPS]], for cards that
		   don't [[Move]] there: [[Structure]]s
			1. [[Action]] has to be directed to the [[Star]]
		2. Between piles within [[Laboratory]] or [[Factory]] row
			1. **Direction**: to corresponding [[Hub]]
3. **Cost**: 1 resource per operation with a card
4. **Manage** is paid only with the [[Power]] of the starter's
   [[Class]], see [[PerformAction]], and works only on cards this
   Class handles

#### Notes

1. E.g. [[Military]] power manages [[Hero]] and [[Ship]] cards
2. Movement keeps the card's [[End]]
