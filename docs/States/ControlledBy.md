1. [[Star]] is **controlled by** faction when either:
	1. The faction has not less [[Control]] in the system than others
	2. There is consensus between all factions with [[Actor]] cards in the system
2. [[Actor]] is **controlled by** its [[Faction]] unless [[Damaged]]
3. [[Structure]] is **controlled by** the faction with the highest [[Control]] in its [[Star]]
	1. If equal, each faction controls its own structures

#### Notes

1. Consequences from the rules on examples:
	1. single faction is present in a star - the faction controls all the structures
	2. single faction has [[Actor]]s in a star - the faction controls all the structures
	3. no [[Actor]]s in a star - every faction controls only own structures
	4. [[Disputed]] star (no consensus) - nobody controls the star, every faction controls only own structures
