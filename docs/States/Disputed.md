1. **Disputed** is a [[Star]] [[State]]
2. [[Star]] is **disputed** when two or more [[Faction]]s have equal
   highest [[Control]] in it
3. Nobody controls a **disputed** Star, the tied factions control only
   their own cards, see [[ControlledBy]]

#### Notes

1. A disputed Star is a front: no faction can start an action from
   it, the tied factions can still [[Takeoff]] there, see
   [[ActiveFor]]
