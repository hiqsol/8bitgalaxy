1. **Disputed** is a [[Star]] [[State]]
2. [[Star]] is **disputed** when two or more [[Faction]]s tie with the highest
   [[Control]]: they all have [[Actor]]s there
3. Nobody controls a **disputed** Star, every faction with Actors there controls
   its own cards, see [[ControlledBy]]
4. [[Structure]]s of a faction without Actors there are out of control: nobody
   can use them

#### Notes

1. A disputed Star is a front: no faction can start an action from it or
   [[Takeoff]] there
2. With [[Politics]] the factions can agree on control
