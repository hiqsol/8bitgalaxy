1. **Wild** is a [[Star]] [[State]]
2. [[Star]] is **wild** when it has no [[World]]
3. A **wild** Star has no [[Class]] and no [[Ability]], cards enter,
   pass and stay in it as in any Star
4. An [[Attack]] on a **wild** Star conquers it:
	1. The attacker draws cards from the World deck until the Attack's
	   participants satisfy the [[Prerequisites]] of one, the others
	   go under the World deck. If none does, there is no conquest
	2. [[Alien]]s defend the Star, as many as that World's
	   [[Price]]
	3. If the attacker wins, the World goes [[Ready]] into the
	   Star: it is not **wild** any more
	4. Else the World goes under the World deck, the Star stays
	   **wild**

#### Notes

1. Stars need no [[Explore]], so movement is fast: a Star is
   conquered only to use it
2. A **wild** Star can be [[ControlledBy]] a faction: control comes
   from cards, conquest gives the World
