1. **Create** action allows to spend [[Resource]]s to create new object(s)
2. [[Social]] cards can only be created from [[Level]] 1
3. Flavour names:
	1. **Raise** for [[Social]]
	2. **Produce** for [[Industrial]]
4. **Direction**:
	1. For [[Actor]]: any [[Star]] to [[BuildingFacility]]
	2. For [[Structure]]: [[BuildingFacility]] to [[Star]] where created
5. **Requirements**:
	1. Target card has to be available at [[Factory]]
	2. Card's [[Cost]] of corresponding power
6. **After creation** target card:
	1. [[Actor]] - goes to [[Discard]]
	2. [[Structure]] - goes to a selected free slot in [[Star]]
7. Multiple cards can be created in a single action
