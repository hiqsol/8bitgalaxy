1. **Tool** is a card [[Type]]
2. **Tool** represents a device, the weakest card, almost like a
   [[Ship]]
3. [[Role]] = [[Unit]], not an [[Actor]]
4. [[Origin]] = [[Industrial]]
5. [[Range]] = 0, can't [[Move]]
6. [[Size]] = current [[Level]] + [[ExtraPrice]]
7. [[Capacity]] = 0, can't carry cargo
8. Carried as cargo of a [[Move]] by any [[Ship]]
9. A destroyed **Tool** leaves the game, it doesn't go to the
   [[Factory]], see [[Destroy]]

#### Notes

1. **Tools** are the junk of the starting deck, see [[StartDraw]]:
   they give little, start no action, clog the [[Hand]] and the
   [[Field]]
2. The player thins them out: [[Takeoff]] parks a **Tool** in a
   Unit [[Slot]] until a Ship carries it away, [[Recycle]] turns it
   into [[Materials]], [[Combat]] takes it as a loss
3. A **Tool** gives its Level and Class like any card, e.g. for
   [[Prerequisites]]
