1. **Tool** is a card [[Type]]
2. **Tool** represents a single-use device, almost like a [[Ship]]
3. [[Role]] = [[Unit]], not an [[Actor]]
4. [[Origin]] = [[Industrial]]
5. [[Range]] = 0, can't [[Move]]
6. [[Size]] = current [[Level]] + [[ExtraCost]]
7. [[Capacity]] = 0, can't [[Transport]]
8. **Tool** is [[Destroyed]] after use
