1. **Objective** is card [[Type]]
2. **Objectives** provide tasks to perform to score victory points, e.g.:
	1. Control 3 [[Star]]s
	2. Have 4 [[Technology]]s
	3. Win 2 [[Combat]]s
3. **Public objectives**: 3 cards face up, available to all players
4. **Secret objectives**: 1 [[Hidden]] card for each player
5. At the end of own [[Turn]] player can score **one** objective:
	1. Public objective is replaced with a new one
	2. Secret objective is revealed
6. First player to get N victory points wins, N is about 6 in a duel

#### Notes

1. Gives the game a clock and a clear winner, see [[Goal]]
2. [[Alien]]s extension can add more objectives
