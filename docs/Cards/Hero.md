1. **Hero** is a card [[Type]]
2. **Hero** represents a faction **leader**
3. [[Role]] = [[Actor]]
4. [[Origin]] = [[Social]]
5. [[Range]] = current [[Level]] - can [[Move]]
6. [[Size]] = current [[Level]]
7. [[Capacity]] = current [[Level]], added to the group's: a Hero
   carries no cargo itself
8. Carried as cargo of a [[Move]] by any [[Ship]]

#### Notes

2. The cooler a **Hero** becomes the more demanding it becomes: its
   [[Size]] grows with [[Level]]
