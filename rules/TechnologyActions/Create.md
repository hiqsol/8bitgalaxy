1. **Create** is [[Culture]] and [[Production]] [[TechnologyAction]]
   of [[Hub]]
2. Flavour names:
	1. **Raise** for [[Social]]
	2. **Produce** for [[Industrial]]
3. **Create** spends [[Resource]]s to create new [[Card]]s
4. A [[Social]] [[Card]] is created only when its [[Weak]] [[End]] has
   [[Level]] 1
5. Multiple [[Card]]s can be created in a single [[Action]]
6. **Direction**:
	1. For [[Actor]]: any [[Star]] to [[Hub]]
	2. For [[Structure]]: [[Hub]] to [[Star]] where created
7. **Requirements**: target [[Card]] has to be available at
   [[Factory]]
8. **Cost**: [[Card]]'s [[Price]]
9. **Outcome**:
	1. [[Actor]] - goes to [[Discard]]
	2. [[Structure]] - goes into the [[Star]]
