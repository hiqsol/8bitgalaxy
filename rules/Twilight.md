1. **Twilight** is the end of the game when no [[Faction]] has won by
   [[Military]], see [[Goal]]
2. **Twilight** is triggered when an end condition says so
3. After the [[Turn]] of the trigger every other player makes one
   last Turn
4. Then the triggering rule decides the winner from the current state

#### Notes

1. Named after the Twilight of Twilight Imperium
2. The triggering player picks the timing, the rivals get the last
   word: every rival has exactly one Turn to answer, and the current
   state decides the winner, so the last move is strong
