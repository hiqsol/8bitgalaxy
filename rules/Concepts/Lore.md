### Technical description

1. Civilizations invent Warp technology that allows:
	1. Travel and communication between stars with faster than light
	   speed
	2. Extraction of huge amounts of energy, though not limitless
	3. Colonization of new star systems
	4. Creation of devastating weaponry
	5. Upgrade of living beings: a **Hero** carries Warp, so it is as
	   potent as a huge ship, see [[Hero]]
2. Warp ships and stations stay in a star system only on **Warp
   orbits**, not gravitational ones: Warp tears space-time, so a star
   system holds only a few Warp orbits, see [[Slot]]
3. But use of Warp is visible through all the universe, so:
	1. All Warp-capable civilizations see each other's activity
	2. Including the **Ancients**, an old civilization
4. Ancients threaten all other civilizations because they:
	1. Have far more advanced technologies
	2. Want to exterminate all newcomers
5. New civilizations have to survive and prosper, and choose to ally
   with each other or fight for dominance
